Model admission protocol

What must happen before a model influences a simulated position.

  1. Engineer stationary inputsReturns, relative trends, volatility, RSI, volume surprise, drawdown, and reference-market context.
  2. Purge the label horizonAn embargo separates training labels from validation and outer-test observations.
  3. Score probabilitiesValidation selection minimizes log loss; outer folds also report Brier score and balanced accuracy.
  4. Compare with a simple baselineAuto mode selects XGBoost only when it beats regularized logistic regression on the inner validation window.
  5. Apply execution assumptionsSignals lag one observation and include configured costs, slippage, exposure, turnover, and drawdown.
